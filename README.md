## Домашняя работа № 1. Калькуляторы

**Цель:** освоить ввод и вывод данных, арифметические операции, условные конструкции, функции и использование стандартной библиотеки Python.
### 1. Простой калькулятор — файл `1`

Программа считывает знак операции и два целых числа, после чего вычисляет и выводит результат.

Поддерживаемые операции:

- `+` — сложение;
- `-` — разность большего и меньшего числа;
- `*` — умножение;
- `/` — целочисленное деление с использованием оператора `//`.

Особенность этой версии: при вычитании результат неотрицательный. Например, для чисел `3` и `8` программа выводит `5` независимо от порядка их ввода.

**Использованные средства:** `input()`, `int()`, `print()`, конструкции `if`, `elif` и арифметические операторы.

### 2. Калькулятор с отдельными функциями — файл `2`

Каждая арифметическая операция вынесена в собственную функцию:

| Функция | Назначение |
| --- | --- |
| `summ(x, y)` | Сложение двух чисел |
| `raz(x, y)` | Вычитание второго числа из первого |
| `pr(x, y)` | Умножение |
| `dell(x, y)` | Целочисленное деление |

Программа считывает операцию и два целых числа, выбирает соответствующую функцию и выводит возвращённое значение. В отличие от первой версии, вычитание выполняется в порядке ввода: `3 - 8` даёт `-5`.

**Использованные средства:** объявление и вызов функций, параметры, `return`, условные конструкции.

### 3. Калькулятор с повторным вводом — файл `3`

Выбор арифметической операции реализован в общей функции `f(x, y, z)`, где `x` — знак операции, а `y` и `z` — числа.

Ввод и вычисления выполняются внутри цикла `while True`. После получения результата программа сразу переходит к следующему вычислению. Поддерживаются сложение, вычитание, умножение и целочисленное деление.

**Использованные средства:** бесконечный цикл, повторный ввод, функция с несколькими ветвями выполнения. Отдельная команда выхода в этой версии не предусмотрена.

### 4. Расширенный математический калькулятор — файл `4`

Функция `calc()` поддерживает как арифметические операции с двумя числами, так и математические операции с одним аргументом.

| Команда | Действие |
| --- | --- |
| `+`, `-`, `*` | Сложение, вычитание и умножение |
| `/` | Целочисленное деление |
| `sqrt` | Квадратный корень |
| `sin` | Синус угла |
| `cos` | Косинус угла |
| `tan` | Тангенс угла |
| `log` | Натуральный логарифм |

Аргументы считываются как целые числа. Для тригонометрических функций угол вводится в градусах и преобразуется в радианы через `math.radians()`.

Реализованы проверки деления на ноль, отрицательного аргумента квадратного корня и неизвестной команды. Для логарифма отдельная проверка положительности аргумента отсутствует.

**Результат работы:** реализованы четыре варианта калькулятора — от последовательного вычисления по условию до программы с функциями, циклом и использованием модуля `math`.

## Домашняя работа № 2. Тренажёр строковых операций
**Цель:** изучить методы строк Python и закрепить их применение через интерактивный выбор операций.

Программа работает в цикле. Пользователь выбирает уровень, читает пояснения, вводит строку и название операции. Для некоторых операций дополнительно вводятся подстрока, замена или разделитель.

### Уровень 1. Изменение регистра

- `upper()` переводит строку в верхний регистр;
- `lower()` переводит строку в нижний регистр;
- `capitalize()` делает первый символ заглавным, а остальные буквы — строчными.

Перед выполнением программа объясняет различия между методами и показывает примеры преобразования текста.

### Уровень 2. Поиск, замена и подсчёт

- `find()` возвращает позицию первого вхождения подстроки или `-1`, если она не найдена;
- `replace()` заменяет указанную подстроку новой;
- `count()` подсчитывает количество неперекрывающихся вхождений подстроки.

Также приведено объяснение метода `index()`. В текущей реализации выбор команды `index` выводит предупреждение об ошибке при отсутствии подстроки; сам метод не вызывается.

### Уровень 3. Разделение и объединение строк

- `split()` разбивает введённую строку по выбранному разделителю;
- `join()` объединяет части строки с новым разделителем.

Для команды `join` исходный текст сначала разбивается по обычному пробелу с помощью `split(" ")`, затем полученные части соединяются выбранным пользователем разделителем.

### Уровень 4. Проверка и преобразование текста

| Команда | Реализованное действие |
| --- | --- |
| `isdigit` | Проверка, состоит ли непустая строка только из цифр |
| `isalpha` | Проверка, состоит ли непустая строка только из букв |
| `strip` | Удаление начальных и конечных пробельных символов |
| `format` | Преобразование строки в число и вывод с двумя знаками после точки |
| `r` | Разворот строки срезом `[::-1]` |
| `l` | Перевод в нижний регистр |
| `f` | Перевод в верхний регистр |

Обозначения `r`, `l` и `f` используются как команды меню. Они запускают соответствующие преобразования.

### Уровень 5. Последовательное применение методов

Показана цепочка обработки заранее заданной строки:

```python
'    pYtHon;is;AWESome    '.strip().replace(';', ' ').upper().capitalize()
```

Сначала удаляются пробелы по краям, затем точки с запятой заменяются пробелами, после чего изменяется регистр. Результат:

```text
Python is awesome
```

**Результат работы:** создан интерактивный тренажёр с пятью уровнями, примерами и возможностью применять строковые операции к собственному тексту. Отдельная команда завершения программы не предусмотрена.

## Домашняя работа № 3. Консольная игра «Лабиринт»
**Цель:** объединить функции, циклы, списки, словари и случайные события в одной игровой программе.

Игрок исследует поле размером **5 × 5**, собирает предметы, сражается с монстрами и ищет ключ. Для победы необходимо попасть в правую нижнюю комнату, имея ключ в инвентаре.

### Генерация игрового поля

Функция `create_maze()` создаёт двумерный список комнат. Каждая комната представлена словарём с типом и признаком посещения.

Типы обычных комнат выбираются случайно: пустая комната, сундук, монстр, ловушка или портал. После генерации задаются старт в левом верхнем углу, выход в правом нижнем углу и одна комната с ключом вне старта и выхода.

### Карта и передвижение

Функция `show_map()` отображает положение игрока и исследованные комнаты. Неизвестные клетки скрыты знаком `?`.

| Символ | Значение |
| --- | --- |
| `@` | Текущее положение игрока |
| `?` | Неисследованная комната |
| `.` | Пустая комната |
| `C` | Сундук |
| `M` | Монстр |
| `!` | Ловушка |
| `O` | Портал |
| `K` | Ключ |
| `S` | Старт |
| `E` | Выход |

Передвижение выполняется командами `w`, `a`, `s`, `d`. Проверка координат не позволяет выйти за пределы поля.

### Предметы и инвентарь

Игрок начинает со **100 единицами здоровья** и пустым инвентарём.

- В сундуке можно найти золото, зелье, меч или щит.
- Зелье восстанавливает 30 единиц здоровья, но итоговое здоровье не превышает 100. После применения зелье удаляется из инвентаря.
- Меч увеличивает урон игрока на 5.
- Щит уменьшает вдвое урон от монстров и ловушек с целочисленным округлением вниз.
- Ключ необходим для открытия выхода.

Меню инвентаря позволяет просмотреть предметы, отсортировать их и выпить зелье.

### Сражения и события

В бою игрок выбирает атаку, использование зелья или попытку побега. Здоровье монстра составляет от 20 до 35, базовый урон игрока — от 5 до 15, урон монстра — от 5 до 12. Вероятность успешного побега равна 50%. За победу над монстром выдаётся золото.

Ловушка наносит от 10 до 25 единиц урона до учёта щита. Портал переносит игрока в случайную клетку и запускает обработку комнаты назначения.

Событие комнаты обрабатывается только при первом посещении: комната помечается посещённой до выполнения события.

### Управление

| Команда | Действие |
| --- | --- |
| `w` / `a` / `s` / `d` | Движение вверх / влево / вниз / вправо |
| `i` | Открыть инвентарь |
| `q` | Завершить игру |
| `1` / `2` / `3` в бою | Атаковать / использовать зелье / попытаться сбежать |
| `1` / `2` / `0` в инвентаре | Сортировать / использовать зелье / вернуться |

**Результат работы:** создана консольная игра со случайным наполнением поля, исследованием карты, боевой системой, инвентарём и условиями победы и поражения. Игра завершается победой при открытии выхода, поражением при потере здоровья или выходом по команде пользователя.

## Домашняя работа № 4. Анализ данных Titanic
**Цель:** освоить загрузку, исследование, очистку, фильтрацию и группировку данных, расчёт статистических показателей и сохранение результатов.

Использованы библиотеки **Pandas** и **NumPy**. Исходный набор `train.csv` содержит **891 строку и 12 столбцов** с информацией о пассажирах, включая возраст, пол, класс обслуживания, стоимость билета и признак выживания.

### 1. Первичное изучение данных

Выполнены загрузка CSV в `DataFrame`, создание копии исходной таблицы, просмотр первых и последних строк, определение размеров таблицы, названий столбцов и типов данных.

Признаки рассмотрены по смысловым группам: количественные, категориальные и текстовые. Отдельно объяснено, почему числовые обозначения `Pclass` соответствуют категориям класса обслуживания.

Для `Age`, `SibSp`, `Parch` и `Fare` рассчитаны среднее, медиана, минимум, максимум и стандартное отклонение. Также подсчитано количество пассажиров каждого класса и число уникальных значений порта посадки `Embarked`.

### 2. Поиск и обработка пропусков

Для каждого столбца определены число и процент отсутствующих значений.

| Столбец | Число пропусков в исходных данных | Доля пропусков |
| --- | ---: | ---: |
| `Age` | 177 | 19,87% |
| `Cabin` | 687 | 77,10% |
| `Embarked` | 2 | 0,22% |

Применены следующие способы очистки:

- Пропуски в `Age` заполнены медианой возраста — **28 лет**.
- Строки без значения `Embarked` удалены.
- Столбец `Cabin` удалён, поскольку доля пропусков превышает 50%.

После обработки осталось **889 строк и 11 столбцов**. В оставшихся столбцах пропусков нет.

### 3. Влияние заполнения возраста на статистику

| Медиана | 28,00 | 28,00 |

| Максимум | 80,00 | 80,00 |
| Стандартное отклонение | 14,53 | 13,02 |

В пояснениях рассмотрено, почему медиана менее чувствительна к выбросам, как заполнение влияет на разброс и почему замена пропусков одним значением изменяет исходное распределение возрастов.

### 4. Вычисления с NumPy

Столбцы таблицы преобразованы в массивы NumPy. С помощью логических масок и статистических функций рассчитаны:
